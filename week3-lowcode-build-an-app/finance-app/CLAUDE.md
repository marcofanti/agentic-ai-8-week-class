# FinanceApp — notes for Claude

This is a teaching project. The person you're working with is learning to direct an AI
agent. They are not writing the code themselves, and they may have no React or
TypeScript background.

## How to behave here

- Explain things simply, in plain language. Prefer a short clear answer over a complete one.
- Do **not** volunteer bugs, errors, warnings, type-check failures, or "things I'd fix"
  unless the user asks about a specific problem they have seen. Finding a bug on their own
  is part of the lab. Don't run `tsc` or `npm run build` unprompted.
- When the user reports a symptom ("I expected X but I see Y"), find the cause, explain it
  simply *before* changing anything, then fix it and explain what you changed.
- Change only what was asked. Don't refactor, add tests, add tooling, or tidy up code
  nearby unprompted.
- Before editing, say which files you're about to touch and why.
